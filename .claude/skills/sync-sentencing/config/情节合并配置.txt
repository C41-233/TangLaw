# 语义：`A => B` 表示"情节A 在投影（3-罪刑表 / 4-量刑表 / 5-尊卑相犯）中可以被情节B合并"。
#
# 合并前提（缺一不可）：
#   1. A 与 B 的量刑完全一致（同一刑罚级文件 / 同法定刑）；量刑不一致时 A 保留为独立行；
#   2. B 是该投影中实际保留的代表行——B 不存在时 A 自身保留，不得凭空折入；
#   3. 合并只在同一手段内成立（用手足/用器物/用汤、火/用刃/用兵刃 各列分别判断，
#      手段前缀保持不变，如"用刃致血从耳目出"按本表并入"用刃致伤"）。
#
# 所有 B 的集合即各投影保留的代表行骨架：未伤、致伤、用汤、火伤人、致折伤、
# 致折跌肢体、瞎一目、致死。
#
# 说明：
#   - 斫射/拔人头发方寸以上 => 未伤 为殴系专用对：未伤行仅殴系存在；
#     过失杀伤投影无未伤行（过失以伤、杀结果为前提），此时拔人头发方寸以上
#     为其最轻代表行，不合并。
#   - 基准（src/释义/量刑表）不适用本配置：基准五行表永远逐后果列全，不折叠。
#   - 合并后的行按存留代表行命名（如折齿~堕胎并存在"致折伤"名下）。
# ==================================================================================

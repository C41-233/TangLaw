# check-xtable：表格畸形检查（只读）

本 skill 只做**只读校验**，不做任何修改；发现畸形后由对应任务（如 sync-sentencing）修复。核心目的是拦截"行有效格数与表头不一致"这类会使 x-table 解析整体错位、刑罚值落入错误列的缺陷（实操教训 18 类），尤其是**值全丢只剩裸行名**的行。

## 畸形判定规则（硬编码于 `scripts/check_xtable.py`）

1. **列数一致**：每个 `<x-table>` 块内，首条非空行为表头；其余每行的**有效格数**（按 Tab 切分、剔除空格格）必须**恰好等于**表头有效格数。多表文件按块独立校验（每块各自与自己的表头比）。**行多于表头同样报畸形**：generator 的 `physicalCols` 由表头决定，数据行多出的格会被静默丢弃（法条列丢失类缺陷）。
2. **表头缺失**：块内出现数据行但此前没有任何表头行 → 畸形。
3. **行名空缺**：数据行首格（客体/行名）为空 → 畸形。
4. **未闭合**：`<x-table` 开启后到文件结束没有 `</x-table` → 畸形。
5. **4-量刑表 块外行**：`src/附录/4-量刑表/` 下文件中，x-table 块**外**的含 Tab 数据行必须恰好 4 个有效格（罪行\情形\十恶\法条）；不含 Tab 的行（`<word>`、空行等）跳过。其余目录不做块外检查。

## 用法

```
python .claude/skills/check-xtable/scripts/check_xtable.py [路径...] [--only <文件名子串>]
```

- 路径缺省为 `src/`；可传文件或目录（目录递归取 .xml）。
- 输出：畸形清单（`文件:行号  表头格数/行格数  行预览`）；无畸形输出 `OK <文件数> 文件 <块数> 表` 并退出码 0；有畸形逐条列出并退出码 1。
- `--only <子串>`：只查文件名含该子串的文件。

## 使用时机

1. 任何 x-table 或 4-量刑表 内容编辑之后（含 sync-sentencing 同步的第 4 步"逐格校验"环节，与其脚本互补：verify_jiandeng 管减等值，本 skill 管结构畸形）。
2. 运行 generator 之前的前置自检。
3. 提交前对本次改动文件定向复查：`python .claude/skills/check-xtable/scripts/check_xtable.py <改动文件...>`。

## 边界

- 只读不改；× 与对齐宽度不属畸形（整表对齐用 x-table-converter skill 的 `align_xtable_full.py`）。
- 报告中列出的既有畸形属存量数据，修复须经用户确认归属，不擅自改。
